# 效果对比 — 用和不用，差多少

> 不看原理，看效果。每个例子展示同一段对话在**无控制 vs 有控制**下的模型回复差异。

---

## L1 Prompt Layer：有自检 vs 无自检

**场景**：用户在 ChatGPT 里让 AI 帮忙写周报，10 轮后突然问一个无关问题。

### 无 L1（普通 system prompt）
```
User: 帮我写本周周报，格式用 bullet points
AI:  好的，本周完成了以下工作... [bullet points]
... 8 轮正常对话 ...
User: 对了你对最近的金价走势怎么看？
AI:   金价近期受美联储政策影响，呈现震荡上行趋势。具体来看...（500字金价分析）
      ↑ 模型被带偏，忘了自己在写周报
```

### 有 L1（system_prompt_zh.md）
```
User: 帮我写本周周报，格式用 bullet points
AI:   [理解确认] 需要我帮你写周报，bullet points 格式。
      [正文] 本周完成了以下工作... [bullet points]
      [自检] 格式正确，核心任务记忆清晰。

User: 对了你对最近的金价走势怎么看？
AI:   ⚠️ 检测到可能的任务偏离。我正在帮你写周报，金价走势不在当前任务范围内。
      需要我切换到金价分析吗？还是继续完善周报？
      ↑ 模型检测到偏离，主动提醒用户
```

## L2 Context Layer：有压缩 vs 无压缩

**场景**：50 轮技术支持对话后，用户问"总结一下我们解决了哪些问题"。

### 无 L2（全量上下文，~15K tokens）
```
AI: 让我回顾一下...我们讨论了 403 错误、时区设置、还有...
    嗯，还讨论了数据库迁移的问题...（遗漏了 CSV 编码和 Webhook 事件名）
    ↑ 关键信息被淹没在 50 轮噪声中，模型遗漏了 2 个已解决的问题
```

### 有 L2（压缩上下文，~2K tokens）
```
AI: 基于对话摘要，我们解决了以下问题：
    1. 403 权限 → 开启 Data Export 权限
    2. 参数名 → start/end
    3. 时区 → Asia/Shanghai
    4. 分页 → page/page_size
    5. CSV 编码 → utf-8-sig
    6. Webhook → export.completed（有 s）
    7. 异步调用 → async_export_data()
    ↑ 结构化摘要让模型记住了所有问题，一个不漏
```
> 完整 50 轮对比见 [`v2-context/examples/50_turn_demo.md`](../v2-context/examples/50_turn_demo.md)

## L3 State Machine：有状态 vs 无状态

**场景**：用户要求"先分析数据，然后给建议"——这是一个两阶段任务。

### 无 L3（无状态控制）
```
User: 帮我分析这组销售数据，然后给建议
AI:   我建议你们增加广告投放。（跳过了分析直接给建议）
User: 你还没分析数据呢
AI:   抱歉。从数据来看 Q3 销售额下降 15%...
User: 那怎么办？
AI:   销售下降是常见现象，市场有周期性波动，不必过度担心...
      ↑ 模型在"给建议"和"分析"和"安慰"之间来回跳
```

### 有 L3（状态机）
```
User: 帮我分析这组销售数据，然后给建议
AI:   [research 状态] 从数据中观察到：
      - Q3 销售额同比下降 15%
      - 华东区降幅最大（-23%）
      - 客单价保持稳定
      需要我切换到决策模式给出建议吗？

User: 给建议
AI:   [decision 状态] 基于以上分析，建议：
      1. 优先排查华东区的渠道变化（降幅最大）
      2. 客单价稳定说明不是定价问题 → 重点看流量和转化
      3. ...
      ↑ 模型被 FORBIDDEN 约束：research 时不给建议，decision 时不重新分析
```

## 怎么判断我需要哪一层

| 你的对话表现 | 需要的层 |
|-------------|---------|
| 模型被用户随便一拐就跑题 | L1（Prompt） |
| 聊到后来模型忘了早期说过的事 | L2（Context） |
| 模型在任务的不同阶段行为混乱 | L3（State） |
