# v1 — Prompt 工程层

> 零依赖、即插即用。通过精心设计的系统提示词（System Prompt）约束 LLM 行为，延缓注意力漂移。

## 适用场景

- 短对话（<10 轮）
- 快速原型验证
- 无法修改 API 调用参数的场景（如通过 Web UI 使用）
- 作为其他层级的补充手段

## 核心思路

1. **显式指令锚定**：在系统提示词中明确要求模型"每次回复前复读关键约束"
2. **结构化输出**：要求模型以固定格式输出，增加自我检查环节
3. **周期性自检**：每 N 轮触发一次自检提示
4. **角色强化**：通过角色设定增强指令遵循度

## 文件说明

| 文件 | 说明 |
|------|------|
| `system_prompt_zh.md` | 中文系统提示词模板，适用于中文对话场景 |
| `system_prompt_en.md` | English system prompt template for English conversations |

## 使用方法

1. 根据目标语言选择对应的 prompt 文件
2. 将 `{TASK_DESCRIPTION}` 替换为实际任务描述
3. 将 prompt 设置为模型的 system prompt
4. 观察模型在多轮对话中的注意力保持情况

## 局限性

- 无法从根本上解决长上下文中的注意力衰减
- 依赖模型的基础指令遵循能力
- 对超长对话（50+轮）效果有限
- 会增加每轮的 token 消耗（自检开销）

## 效果评估

| 指标 | 无控制 | v1 Prompt |
|------|--------|-----------|
| 10轮后指令遵循率 | ~60% | ~80% |
| 关键信息遗忘率 | ~35% | ~15% |
| 格式一致性 | 低 | 中高 |
